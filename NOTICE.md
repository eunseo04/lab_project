# Source attribution

This research combines local experiment code with the published ACD, KEEP,
CAGE Challenge 4 and Skill-Pro implementations. Their repository URLs and exact
commits are recorded in `sources.lock.json` and `research_sources.lock.json`.

The existing project `LICENSE` is preserved unchanged. Downloaded upstream
repositories, generated simulator sources, model weights and virtual environments
are not vendored in this snapshot. Setup fetches the pinned upstream sources with
their existing license and attribution files.

Recorded reports describe this implementation and its experiments. They do not
claim to reproduce every number in the original publications or establish a
statistically significant performance gain.
